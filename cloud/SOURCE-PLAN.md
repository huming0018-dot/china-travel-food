# 上海美食图鉴 · 信源规划（Source Plan）v1

> 上位契约：`cloud/CRAWLER-MODULE-SPEC.md`、北极星宪法。本文件回答「**数据从哪来、用什么通道、多久采一次、能当证据还是只能当线索**」，覆盖**网站 / KOL / 综艺 / 独立 App / 地图 / 官方 / 监管 / 海外**全类型。
> 唯一立场：**口味为唯一最高准则、宁空不假**；榜单、KOL、综艺、官方都只是**发现入口或辅助信号**，不能替代真实食客堂食口味。
> 配套账本：`research/coverage/source_registry.jsonl`（机器可读，99→本期增补）、`cloud/tool_registry.json`（工具能力/成本/封号）。

---

## 1. 信源 → 数据族 → 证据等级（总原则）

五族数据（见 CRAWLER-MODULE-SPEC §1）：**A 宇宙/目录 · B 事实 · C 口味 UGC · D 动向事件 · E 关联关系**。

| 信源类型 | 主要供给 | 可作「口味证据」？ | 角色 |
|---|---|---|---|
| 地图 / POI | A、B（电话/坐标/营业时间/人均） | 否（仅聚合星级，无正文） | 事实底座 + 抽样框 |
| 权威榜单 / 指南 | A、E、背书分 | 否（非堂食） | 发现 + 背书（权重低） |
| **UGC 食客平台** | **C（核心）** | **是（唯一口味来源）** | **口味证据** |
| KOL / 美食家 | 线索、特征标签 | **否（个人探店=1 个整理者声音，不计口味）** | 发现 + 标签 |
| 综艺 / 影视 | A、D、E（主厨） | 否 | 主厨发现 + tracking |
| 独立 App / 预约平台 | A、D（新店/快闪库存） | 否（预约/策展平台） | 新店探针 + 覆盖参照 |
| 官方 / 第一方 | B、D（事实/事件） | 否（营销口径） | 事件 + 事实存证 |
| 媒体 / 长文 | 线索、佐证 | 否（非食客） | 佐证 + 背景 |
| 监管 / 登记 | 负面、B（安全/资质） | 否 | 负面清单 + 事实 |
| 海外平台 | A、D（海外名店入沪）、佐证 | 部分（Tripadvisor/Google 真实食客可作弱口味） | 海外进入 + 交叉 |

**三条铁律**：① 只有真实食客**堂食正文**（含具体菜品/做法/食材）能进 score_taste；② 媒体/官方/KOL/榜单**不得冒充 UGC**（`common.source_kind` 确定性判定）；③ 每条结论可溯源到注册源（source_id + url）。

## 2. 分类信源规划

### 2.1 权威榜单 / 指南（发现 + 背书）
| 源 | 采集方式 | 节奏 | 说明 |
|---|---|---|---|
| 米其林 Guide（sitemap 全量） | L0 公开页 sitemap（纯 requests，202 空体则浏览器） | 每周全量 + 每日新增 | 权威召回已 0 missing；新店/必比登第一时间发现 |
| 黑珍珠 | L0 公开页 | 年度发布 + 季度复核 | 已召回，hold 店转口味核验 |
| Asia's 50 Best / Gault&Millau | L2 网页只读 | 年度 + 季度 | 背书信号 |
| 携程美食林 | L0/L2 | 半年 | 辅助 |

### 2.2 地图 / POI（事实底座 + 抽样框 F5）
- **高德**（place/text、geocode、SK 签名，多 key 池）、**腾讯 LBS**、**百度地图**；海外 **Google Places**。
- 供给：电话/坐标/营业时间/人均/POI 是否存在；**只取聚合星级，不作品味正文**。
- 跨源故障转移（lesson 80）：单源配额耗尽不短路；选正确分店（lesson 81，商场/区域 token），电话只从选中分店取、宁空不假。

### 2.3 UGC 食客平台（口味证据核心）
| 源 | 通道 | 节奏 | 可靠性/边界 |
|---|---|---|---|
| **小红书** | L3：routed Apify（**atomus per-result 先探→不足 opspilot**，约 $0.18/店）；自有登录号仅兜底 | 每日滚动 | 真实食客堂食；软广概率过滤；code=0 空 data=软限流放慢 |
| 大众点评 | L2 网页只读 / L0 POI 开放平台（正文受限） | 每日 | 正文反爬严；聚合分仅参考 |
| 马蜂窝 | L0 POI + L2 | 每周 | 游客餐，弱信号 |
| 豆瓣小组 | L2 公网 | 每周 | 本地食客长文，量小质可 |
| 下厨房 | L2 | 月度 | 偏菜谱，探店弱 |
| Tripadvisor / Google Maps（海外） | L0 API / L2 | 每周 | 海外食客真实评价，可作**弱口味**交叉 |

### 2.4 KOL / 美食家（发现 + 特征标签，**绝不计口味**）
- **库内 watchlist `food_kol_watchlist`（115：B 站 103 / cross 9 / 微信 1 / web 2）**；`food_kol_posts/mentions` 由 kol_monitor 每 6h 增量。
- 高可信美食家种子（`research/authority/kol_seed.json`）：**沈宏非、殳俏、陈晓卿**等作家/导演；trust=high。
- **接线（本期）**：`kol_router.py` 把 mentions 做「碎片守卫 → 高德**餐饮** POI 验真（typecode=05）→ 独立 KOL 声音数分级」，干净线索进 `kol_lead_fill.json`，已在库进 alias_link，碎片/无 POI 进 rejected。
- 用法：KOL 到访只生成**特征标签**（如「美食作家到访」）；新店须 ≥2 独立声音且过食客口味核验才 admission。

### 2.6 独立 App / 预约平台（新店/快闪探针 + 机制参照）

### 2.7 官方 / 第一方（事件 + 事实存证）
- 品牌**微信公众号、微博蓝 V、抖音官方、小程序、商场导购**：新店/停业/搬迁/主厨更迭/联名快闪的**第一方事实**（治 Nuits 搬家）；营销口径，不作品味。
- 连接器：off_wechat_oa / off_weibo / off_douyin / off_wechat_mini / offline_mall_directory。

### 2.8 媒体 / 长文（佐证 + 背景）
- SmartShanghai、That's Shanghai、TimeOut、Nomfluence；行业媒体（红厨网/名厨/餐饮内参/Foodaily）。
- 用于背景与交叉佐证，不计口味；行业媒体帮助识别集团/资本/预制信号。

### 2.9 监管 / 登记（负面清单 + 事实）
- 食品抽检（市场监管）、企查查/天眼查/启信、国家企业信用信息、食品生产许可、裁判文书、失信被执行人、商标。
- 用于食品安全、集团/关联关系、负面清单；权威多源确认的事实可直接打标。

### 2.10 海外平台（海外名店入沪 + 交叉）
- Google Places、Tripadvisor、Instagram Graph、YouTube Data、Reddit、TikTok Research API。
- 重点追踪**海外米其林/热门店入沪、飞行主厨、海外集团开店**（D 族 overseas_entry / guest_kitchen）。

## 3. 通道阶梯、节奏与成本

| 通道 | 含义 | 成本 | 封号风险 | 优先 |
|---|---|---|---|---|
| **L0** 公开/官方 API、地图、官方稿 | 地图 REST、米其林/黑珍珠、官方公众号/新闻稿 | 免费 | 无 | 最高 |
| **L1** 匿名签名直连 | xhshow 签名、B 站 wbi | 免费 | 低（能力受限） | 高 |
| **L2** 网页只读 | SmartShanghai/TimeOut/点评公网/B 站 | 免费 | 低-中（部分需代理） | 中 |
| **L3** 登录账号 / Apify 兜底 | routed Apify（atomus→opspilot）；自有号池 | 付费（约 $0.18/店） | 我方零封号（actor 账号） | 兜底 |

**节奏建议**：
- 实时/每日：地图事实补齐、小红书口味滚动、事件 sweep、看门狗（20min）、进度播报（10min）。
- 每 6h：kol_monitor（:37）→ **kol_router（:53）**。
- 每周：米其林/黑珍珠全量召回、海外平台交叉、独立 App 新店探针。
- 每周一/四：events_apify 全类目 sweep（已接 cron）。
- 每日 02:00：自进化复盘（lessons→固化脚本→信源注册）。

**源质量评分（reliability 0–1）**：依据「是否常发软广 / 可否交叉验证 / 更新频率 / 专业度」；低质只作线索、高质才作证据；定期复核、可淘汰。媒体/官方过 `source_kind` 定性 + admission gate，禁止冒充 UGC。
