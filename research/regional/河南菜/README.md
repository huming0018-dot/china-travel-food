## 稀缺格标注
- **豫菜(开封洛阳)×正餐**：上海能做正经豫菜正餐的极少，仅荣豫(商场新派豫菜)与熹餐厅(豫菜bistro)两家，标"供给稀缺"。
- **烩面×面食**：上海烩面均为河南人聚居区社区档口（瘸子烩面24h连锁、河南滋补烩面申浦路/民民路、豫陕坊青厦路），无独立名店级堂食证据，标"供给稀缺"，不硬凑。
- **胡辣汤/水煎包**：均为早餐档口，多为同店经营，无独立专门店。

- **荣豫·河南菜(ONE Shanghai L302)**：上海豫菜正餐主力，信阳荆芥鱼头汤/焖罐肉有堂食原话；连锁新店，"新荣记平替"软文+代金券，soft_ad_penalty=10。
- **方中山胡辣汤(康定路1469号)**：澎湃新闻"河南最辣胡辣汤"背书+高德4.6/人均23+抖音，高德坐标(31.228623,121.430059)已填；浦东东昌路520号另有旗舰店。
- **王凯阳河南水煎包(浦东康桥)**：上游新闻+大河报双news源，5毛/1元2个水煎包、3元胡辣汤，春节被全网催开门，纯河南老乡早餐摊无软广。
