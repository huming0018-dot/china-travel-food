## 4. 关键发现与方法论记录

1. **潮汕牛肉火锅在上海供给充足**：连锁（今日牛事/左庭右院/八合里）+ 独立店（下山虎/宽马记/草根/潮牛嗨）+ 社区店，覆盖亲民到中档全档。注意区分：今日牛事/左庭右院为上海老牌连锁（必吃榜背书），下山虎为2026年新店网红（排队200桌，软广扣分从严）。
2. **生腌/打冷是潮汕特色，上海有专门店**：海缘居（马当路）、神更仔（汉口路）、潮府夜档（嘉定马陆）、潮人姐妹轩（海宁路）。生腌膏蟹/生腌虾为招牌。
3. **高端潮汕菜标杆=菁禧荟**：2026年晋升米其林二星+黑珍珠三钻，BFC外滩旗舰店+北外滩SELECTION BY DU。头家夜粥（广州米其林推荐）2026年6月开出上海外滩店，人均300+，为高端砂锅粥代表。
4. **潮汕甜汤2026年集中入沪**：汕鹤（汕头排队王）、汕心（上海本土新连锁）同年开进人广来福士，人均25–35，平价甜品档。
5. **反软广重点**：下山虎（巨鹿路新店）营销密度极高，排队200桌但需辨网红vs真好吃；家府/今日牛事/潮禧等连锁代金券推广频繁，已扣分。
