## 2. 稀缺格清单

| 格子 | 稀缺原因 | 处置 |
|---|---|---|
| A4 博山菜 | 上海未找到博山菜专门店（酥锅/豆腐箱/爆炒腰花为博山正脉）。鲁菜正餐菜单偶有爆炒腰花但非博山正脉。 | 标记"供给稀缺"，候选池留空待后续 |
| A3 孔府菜 | 上海无独立孔府菜馆。鲁采菜单含孔府酱烧驴尾等孔府元素，但非专门孔府宴席。 | 标记"供给稀缺"，鲁采慎余里店兼挂孔府元素 |
| B3 山东包子/煎饼/火烧 | 上海无独立山东包子/煎饼/火烧专门店。鲁采的沂蒙六味大煎饼是FD菜品(98-158元)，非独立小店。 | 标记"供给稀缺" |
