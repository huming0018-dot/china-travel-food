## 稀缺格标注

1. **锡菜浓油赤酱**：上海供给稀缺，仅米桃(久光中心)一家苏锡融合菜可挂锡菜。无锡本地老字号(三凤桥/聚丰园)未在上海开店。建议标注"供给稀缺"。
2. **徐海羊肉/地锅鸡**：上海供给稀缺，仅普陀镇坪路聚集区(徐州印象/徐州味道)2家。无高端徐海菜餐厅。建议标注"供给稀缺"。
