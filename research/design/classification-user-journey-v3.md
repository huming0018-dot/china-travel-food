# 上海美食图鉴 · 分类机制与用户旅程重设计 v3

> 视角：信息架构 / 分类学。本文是对「包馅面食无独立轴」「饼类错放精品店」「搜索意图解读不明」三大顽疾的系统性重设计。
> 原则：**按食客真实心智建轴，维度正交可叠加，主营定类、含有不挂。**
> 版本：v3（取代 architecture-v2-atlas §5 的旧版 user journey 表；与 cuisine-classification-engine v2 兼容扩展）。
> 日期：2026-09-24。数据库现状：Supabase `bdwrhshgdeghgyzwpxnl`，restaurants 1497 家，cuisines 表含 dimension 字段。

## 0. 问题诊断（为什么要重设计）

| # | 现状问题 | 根因 | v3 对策 |
|---|---|---|---|
| P1 | 无锡菜/生煎/小笼/馄饨/锅贴被挤在正餐地域类里，用户搜"想吃饺子"找不到 | 食材轴扁平（约20个标签），"饺子"与"面/饭"同级但无"包馅面食"父节点；无锡菜店只挂了菜系叶没挂食材叶 | 食材轴引入两级结构：建「包馅面食」父叶 + 8个子叶；一家无锡小笼店同时挂"苏菜·无锡菜"菜系叶 + "包馅面食·小笼包"食材叶 |

## 1. 联网研究发现（带来源）

### 1.1 Tabelog（日本）：专门店品类是独立一级ジャンル，不归菜系

Tabelog 是全球最精细的餐饮分类之一。关键发现：**拉面、饺子、小笼包、沾面、担担面、刀削面都与"中華料理"同级，是独立的第一ジャンル（primary genre）**，不是中華料理的子类。

- Tabelog 百名店选拔规则原文：第一ジャンル为「ラーメン」「つけ麺」「油そば・まぜそば」「台湾まぜそば」「担々麺」「汁なし担々麺」「刀削麺」任一即可入围拉面百名店。→ 来源：https://award.tabelog.com/sp/hyakumeiten/ramen_west/2025/
- 店铺展示形如「中華料理、餃子、小籠包」——主品类（中華料理）+ 副品类（餃子/小籠包）并列，多标签。→ 来源：https://tabelog.com/cn/rstLst/RC0310/
- Tabelog 收录量：ラーメン 52,384 店、カフェ 131,715 店、和食/日本料理/中華料理各自独立计数。→ 来源：http://u.tabelog.com

**对本项目的启示**：当某品类在上海有 ≥20 家专门店供给时，它应当成为食材轴的一个可直达叶子（如"包馅面食·生煎"），而不是埋在"本帮菜"或"苏菜"地域叶里。食客心智是"我想吃生煎"而非"我想吃苏菜·锡菜下面的生煎"。

### 1.2 Yelp / 美媒：专门品类平级，不按菜系收纳

Yelp 商家分类是多标签扁平列表（如 "Mexican, Burgers, Gastropubs"），一家店可挂多个。美国地方媒体的"按菜系浏览"导航里，**Ramen、Sushi、Burgers、Pizza、BBQ、Steakhouses 都是独立入口**，并不 under Japanese / American。

- Marin Magazine 浏览导航：Bakeries / BBQ / Breakfast·Brunch / Burgers / Chinese / Fine Dining / Ice Cream / Indian / Italian / Mexican / Pizza / Ramen / Sandwiches / Seafood / Steakhouses / Sushi / Thai。→ 来源：https://marinmagazine.com/food-drink/where-to-eat/where-to-eat-fairfax/amp/
- Yelp 要求商家填 granular cuisine + service style + price range + features（outdoor/delivery/reservations），即菜系与服务形式正交。→ 来源：https://www.nineguides.com/starting/restaurant-online-presence-setup/

**启示**：Ramen/Sushi 在美国被从日料里拎出来做独立入口，正是因为食客心智按"想吃什么"检索。本项目的"包馅面食"同理——它是跨菜系的（沪式生煎、苏式小笼、川式抄手、粤式虾饺烧卖都属包馅面食家族），必须独立成食材轴，不能塞进某菜系。

### 1.3 OpenRice（香港）：菜式 × 食物类型双轴

OpenRice 香港的店铺标注形如「港式 / 火锅」「川菜(四川) / 火锅」「港式 / 粉面·米线」——**主菜式（cuisine）+ 副食物类型（food type）两个正交标签并列**，可叠加筛选（地区/菜式/热门，最多5条件）。

- 来源：https://www1.openrice.com/zh-cn/hongkong/restaurants/cuisine/港式
- FAQ：用户搜"元朗甜品""尖沙咀放题"，即地区+品类联合；选择不多于5个条件，可再点取消。→ 来源：https://campaign.openrice.com/faq/topic/功能介绍/

**启示**：这正是本项目要走的"菜系轴 × 食材轴"正交模型，且香港食客心智里"火锅/粉面/甜品"是与"港式/川菜"平行的筛选面。

### 1.4 大众点评：用户按"菜"找店，不只是按"菜系"

- 大众点评 2025 上线"王牌菜榜"，覆盖 34 城近 1500 道菜——红烧肉、白斩鸡、排骨年糕、寿喜烧、沙拉、三明治各有独立榜单与商户排名。→ 来源：https://app.myzaker.com/news/article.php?pk=6aab946a32ce400376000000
- 抖音/美团外卖的三级品类：一级（美食/甜点/饮品）→二级（简餐/中式正餐/全球美食/小火锅）→三级（具体品类）。→ 来源：https://www.iesdouyin.com/share/video/7625195038200952305

**启示**：食客真实检索单元是"一道菜/一个食物类型"（饺子、生煎、排骨年糕），不是"苏菜"。食材轴必须能接住"想吃 X"的 query。

### 1.5 中式面点专业分类学：按面团/熟制/形态三维交叉

《中式面点基础》教材的标准分类：
- **按面团**：水调面坯 / 膨松面坯 / 油酥面坯 / 米粉面坯 / 澄粉面坯；
- **按熟制**：煮（水饺）、蒸（馒头/小笼）、煎（锅贴/生煎）、炸、烤、烙、炒；
- **按形态**：糕、饼、团、酥、包、饺、粽、粉、面、烧卖、馄饨。
- 来源：https://www.xinsijiaocai.com/uploadfile/2026/0625/20260625032840863.pdf ；http://cloud.hz-edu.cn/jpbook/upload/pdf/中式面点基础（样章）.pdf

**包馅家族的专业区分**（皮/熟制/形态三维）：
| 品类 | 面团 | 熟制 | 形态/关键特征 |
|---|---|---|---|
| 饺子 | 水调冷水面 | 煮/煎 | 半月形，干吃或蘸醋 |
| 锅贴 | 水调面 | 煎（底脆） | 长条形，一端露馅 |
| 小笼包 | 中温水调薄皮 | 蒸（竹笼） | 含皮冻汤，江南源 |
| 生煎 | 膨松发酵面 | 煎（底焦） | 上海派，带汤、撒芝麻葱花 |
| 馄饨 | 极薄方/梯形皮 | 煮（汤/干拌） | 川式叫抄手 |
| 烧卖 | 薄面皮 | 蒸 | 开口露馅，荷叶边 |
| 汤包 | 水调薄皮 | 蒸 | 灌汤，淮安/镇江/靖江派 |
| 汤圆 | 糯米粉 | 煮 | 团圆形，甜/咸 |
- 来源：https://dragontrail.cc/travel-guide/chinese-dumplings ；https://www.deeptrip.com/ai/dumplings-in-china-guide ；https://susubao.vn/zh/blog/jiao-zi-zhong-lei

### 1.6 饼类：可丽饼 ≠ 葱油饼，是不同文化根

- 可丽饼（crêpe）：法国布列塔尼源，无酵薄饼，分甜可丽饼（crêpe sucrée，甜品/小吃）与咸可丽饼（galette，荞麦面，轻食正餐）。薄、软、卷折。→ 来源：https://www.owiki.org/wiki/Crêpe ；https://skinnypancake.com/blog/whats-the-difference-between-a-crepe-and-a-pancake/
- 美式松饼（pancake）：厚、膨松、早餐/Brunch 食品。→ 来源同上
- 中式葱油饼/手抓饼/烧饼：水调/发酵面团，烙烤，正餐/早餐主食。

**结论**：精品可丽饼店（水果奶油卷）在食客心智里是**甜品/小吃店**，不是"饼"正餐。把它挂进正餐"饼"是维度错配。

### 1.7 Faceted 导航 UX 最佳实践

- 每个 facet 值旁显示数量（"饺子(47)"），数量为0的置灰，避免死路；动态联动。→ 来源：https://www.btng.studio/articles/top-ecommerce-ux-filter-design-patterns-practical-tips-for-2025
- 多选叠加、标签可一键撤销、筛选条件以 chip 展示。→ 来源：https://www.aufaitux.com/blog/filter-ui-design/
- 顶级分类控制在 5–7 个；排序支持价格/评分/距离/置信。→ 来源：https://www.gitnexa.com/blogs/mobile-app-ui-ux-design-best-practices
- IA 铁律：按用户心智模型而非内部组织结构；层级≤3层；提供搜索兜底。→ 来源：https://aj-geddes.github.io/useful-ai-prompts/skills/information-architecture/

## 2. 四维正交分类体系（核心交付）

### 2.0 维度总览

> 一家店在**每个维度**可挂 0–N 个叶子；维度之间正交，禁止把形式当菜系、把食材当菜系。

| 维度 | 回答的问题 | dimension 字段值 | 叶子数（v3） | 挂叶规则 |
|---|---|---|---|---|
| **菜系轴 Cuisine** | 吃哪国/哪派风味？ | `dimension='菜系'` | 见 §2.1 | 主营风味，1主+多挂 |
| **食材轴 Ingredient** | 想吃什么食物？ | `dimension='食材'` | 见 §2.2（两级） | 主营才挂子叶，含有折叠 |
| **形式轴 Format** | 多正式/什么店型？ | `dimension='形式'` | 见 §2.3 | 1主形式 |
| **场景轴 Occasion** | 什么场合/时段？ | `dimension='场景'` | 见 §2.4 | 可多挂 |

> 兼容约束：菜系树保留现有 8 虚拟根（中餐/亚洲/欧洲/非洲/北美洲/南美洲/融合菜/非正餐）。食材轴当前约20个扁平标签，v3 改为"父叶→子叶"两级，**同名全局唯一、不按菜系拆**（沿用 flatten_ingredients.py 原则）。

## 3. 包馅面食品类专项（P1 根治）

### 3.1 为什么必须独立成食材父叶

1. **跨菜系**：饺子（鲁/东北）、馄饨（川抄手/广云吞/沪大馄饨）、生煎（沪本帮）、小笼（苏/锡/沪）、烧卖（粤/京）、汤包（淮扬）分属至少 6 个菜系叶。若不独立食材轴，用户想"吃饺子"必须遍历东北菜/鲁菜/川菜/本帮菜，Tabelog 已证明专门品类应独立（§1.1）。
2. **供给足够**：上海生煎/小笼/馄饨/锅贴店数量远超 20 家，达到 Tabelog "可独立成ジャンル" 的阈值。
3. **食客心智**：搜索 query 是"附近生煎""想吃小笼"，不是"无锡菜"（§1.4 大众点评王牌菜榜逻辑）。

### 3.2 9 个子叶的专业区分判据

| 子叶 | 面团 | 熟制 | 归属菜系叶（多挂） | 上海典型店型 |
|---|---|---|---|---|
| 饺子 | 冷水面 | 煮/煎/蒸 | 东北菜/鲁菜/北方菜 | 东北水饺馆、锅贴饺子店 |
| 馄饨 | 极薄皮 | 煮(汤/干拌) | 川菜(抄手)/本帮(大馄饨)/粤菜(云吞) | 大馄饨店、红油抄手店 |
| 锅贴 | 水调面 | 煎(底脆) | 本帮菜/上海本地 | 上海锅贴店 |
| 生煎 | 发酵面 | 煎(底焦+芝麻) | 本帮菜★ | 大壶春/小杨生煎类 |
| 小笼包 | 中温薄皮 | 竹笼蒸(含汤) | 苏菜·无锡菜/本帮菜/苏帮菜 | 无锡小笼店、南翔类 |
| 汤包 | 薄皮 | 蒸(灌汤) | 苏菜·淮扬菜 | 淮安/镇江汤包馆 |
| 烧卖 | 薄皮 | 蒸(开口) | 粤菜/京菜 | 粤式早茶、烧卖专门 |
| 包子 | 发酵面 | 蒸 | 全国/港式 | 叉烧包、鲜肉大包 |
| 汤圆 | 糯米粉 | 煮 | 本帮/宁波/江南 | 宁波汤团店 |

> 边界规则：虾饺（粤式澄皮虾饺）挂"包馅面食·烧卖"同族或单列"虾饺"——v3 先并入烧卖/粤式点心，若供给>15家再拆。

## 4. 饼类清理规则（P2 根治）

### 4.1 "饼"食材叶的子节点与归属

```
食材·饼
├─ [正餐/早餐类] 中式烙烤饼
│   ├─ 葱油饼 ── 本帮/上海早餐
│   ├─ 手抓饼 ── 台湾/街头小吃
│   ├─ 烧饼   ── 徽菜沿淮/江浙(蟹壳黄)
│   ├─ 煎饼果子 ── 天津/街头
│   └─ 鸡蛋饼/葱油饼摊
├─ [轻食类] 咸可丽饼 galette
│   └─ 布列塔尼荞麦咸饼 ── 欧洲·法餐·轻食
└─ [不进本叶！转甜品类]
    ├─ 甜可丽饼(水果奶油) ── 食材·甜品·甜可丽饼 + 菜系·欧洲·法餐 / 非正餐·咖啡甜品

    └─ 港式班戟 ── 食材·甜品 + 粤菜·港式
```

### 4.2 归属裁决规则（写进分类引擎 DISH_CUISINE_MAP）

| 店名/信号 | 错误归 | 正确归 | 判据 |
|---|---|---|---|
| 精品可丽饼店（草莓奶油卷/冰淇淋卷） | 食材·饼 | **食材·甜品·甜可丽饼** + 非正餐·咖啡甜品 | 主营=甜品，堂食<30min，无咸galette |
| 咸galette专门店（火腿芝士荞麦饼） | 食材·饼 | **食材·饼·咸可丽饼** + 欧洲·法餐 | 咸口、可作主餐 |
| 葱油饼摊/早餐车 | 食材·饼 | 食材·饼·中式烙烤饼 + 形式·快餐/早餐 | 正餐主食 |
| 印度薄饼naan/dosa | 食材·饼 | **菜系·亚洲·印度菜**（不挂饼食材叶） | 饼是咖喱配菜，主营印度菜 |
| 烧饼店（蟹壳黄/黄山烧饼） | 食材·饼 | 食材·饼·中式烙烤饼 + 对应菜系 | 中式面点 |
| 舒芙蕾松饼网红店 | 食材·饼 | **食材·甜品·松饼** + 形式·Brunch | 甜品/下午茶 |

→ **铁律**：食材叶"饼"只收"把饼当正餐/早餐主食"的店；甜品化、精品化、Brunch化的饼一律转"甜品"叶，不堆进正餐饼。

## 5. 主营 vs 含有：量化判据（强化现有引擎）

> 沿用 cuisine-classification-engine §1，v3 给出可执行的三信号量化阈值。

| 信号 | 主营（挂叶） | 含有（不挂叶） |
|---|---|---|
| **招牌菜占比** | 该品类单品占招牌/菜单主体 **≥ 50%** | **≤ 33%** 且非店名所指 |
| **店名指向** | 店名含该品类词（"XX生煎""XX小笼""XX面馆"） | 店名指向另一主营品类 |
| **食客心智** | 食客"为吃 X 而来"，点评高频词=X | X 只是搭配/引流项 |

**裁决规则**：
- 三信号 ≥2 个指向某品类 → 主营，挂该食材子叶。
- 招牌占比 ≥50% 但店名指向他类 → 标冲突，走 LLM 裁决（§6）。
- 介于 33%–50% 之间 → 主营挂主品类，次品类仅在"另有N家菜单含此食材"折叠区出现（不进筛选主结果）。
- **菜单里个别饼/甜单品不挂叶**（甜汤店卖2道gelato → 不挂Gelato，沿用汕鹤案例）。

**v3 新增冲突检测规则**：
1. **包馅面食悬挂检测**：挂了"生煎/小笼/馄饨"食材叶，但菜系叶为空 → 补菜系叶（本帮/苏菜·无锡菜等）。

3. **饼类页面分两区**：上半"中式烙烤饼（正餐主食）"，下半"甜可丽饼/松饼（甜品）"，避免用户误把精品可丽饼当正餐。
4. **PWA Service Worker**：分类/筛选逻辑变更后需注销旧 SW + 清 caches + `?nocache=` 重载（沿用 cuisine-classification-engine §7C 教训）。
5. **空结果引导**：筛选结果为 0 时，提示"放宽条件"并展示相邻叶子（如选了"小笼包"为空 → 提示"看看 汤包 / 生煎"）。

## 9. 与现有架构的兼容与迁移说明

- **菜系轴**：沿用 8 虚拟根，不破坏现有 cuisines 行；v3 仅补充地方菜/苏菜下的叶子细化。
- **食材轴**：现有 ~20 扁平标签保留为父叶；新增"包馅面食"父叶 + 9 子叶；"饼"保留父叶 + 拆 3 子叶。**同名全局唯一，不按菜系拆**（沿用 flatten_ingredients.py）。
- **restaurant_cuisines 多对多**：一家店同时挂菜系叶 + 食材叶 + 形式叶 + 场景叶，全部走 RC 关联表，无需改表结构。
- **数据回填顺序**：①建包馅面食/饼子叶标签；②对 1497 店跑 §6 冲突脚本；③LLM 裁决 conflicts；④成对迁移无锡菜/生煎/可丽饼错放店；⑤前端 facets 上线。
