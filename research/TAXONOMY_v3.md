# 上海美食图鉴 · 分类体系与搜索机制 v3（权威单一真相源）

> 本文件是重构菜系树、形式判定、权威名单比对、私房菜采集与前端导航的唯一依据。

## 一、菜系树：大陆 → 国家；中餐与融合菜独立

**一级结构（前端一级菜单）**：中餐 / 亚洲 / 欧洲 / 非洲 / 北美洲 / 南美洲 / 融合菜。
除中餐、融合菜外，一律按「**地理大陆 → 地区 → 国家**」层级，国家下再按该料理的烹饪形式/店型细分。

## 二、非正餐场景：咖啡 / 面包 / 甜品 / Bar 四分开

一级"非正餐（轻食·饮品）"下四个**独立**二级，禁止再合并为"咖啡甜品"：
1. **咖啡 Coffee**：精品咖啡、社区咖啡、自烘豆/手冲专门、连锁咖啡（工业化标注）
2. **面包 Bakery**：酸种/可颂专门、面包烘焙坊、日式面包
3. **甜品 Dessert**：蛋糕/法式甜品、和果子、糖水、冰淇淋·Gelato、松饼/铜锣烧、刨冰
4. **Bar 酒吧**：鸡尾酒吧、葡萄酒/自然酒吧、威士忌吧、清吧
（Brunch 作为"形式"标签横跨咖啡/轻食，不单列为菜系；居酒屋归日料×夜宵，不归 Bar。）

## 三、形式判定机制升级：Fine Dining 优先于 Bistro（核心修复）

**判定优先级**：Fine Dining > Bistro / Casual / 快餐 / 大排档 / Brunch / 下午茶 / 夜宵 / 自助 / 酒吧 / 茶馆 / 私宴 / 美食广场。

### Fine Dining 判据（套餐制为核心，需同时满足）
- 以 **tasting menu / 套餐 / 主厨发办**为主，非自由单点；
- 人均 **≥250**（硬门，星级店实际多 ≥500）；
- 多道式、正式服务、预约制、餐酒搭配、仪式感；星级/50佳/高端酒店内为强信号。

### Bistro 判据（必须在"非 Fine Dining"前提下）
- 休闲餐酒、单点开胃菜+主菜、小馆/吧台、人均约 100–400，源于法式 bistrot / 餐酒馆。

### 明确禁止（治误判）
- **不得仅凭"有佐餐酒/酒单/吧台座/开放式厨房/店名含 Atelier·Studio·Lab"判 Bistro**——Fine Dining 都有酒单、吧台、开放厨房；
- 星级店、套餐制店一律不得判 Bistro。

### 纠错三家（重新归类 + 重新取证）
| 店 | 错误归 | 正确归 |
|---|---|---|
| L'Atelier de Joël Robuchon 乔尔卢布松 | Bistro/其他 | **欧洲·法国·Fine Dining**（二星，外滩18号） |
| T'ang Court 唐阁 | Bistro/其他 | **中餐·粤菜·Fine Dining**（朗廷，星级） |
| Ling Long 玲珑 | Bistro/其他 | **中餐·创新菜·Fine Dining**（一星，华尔道夫，+分子/先锋标签） |

## 四、米其林 / 黑珍珠权威名单全量比对闭环（治 Cheeva Thai 类缺失）

**闭环流程**：
1. 全量分页拉取（店名+星级+官方菜系+地址+详情URL）；
2. 与库逐家比对（模糊名+地址）：在库 / 缺失 / 已关店（显式排除）；

5. 差异清零（或每条有显式理由：关店/城市不符）才完工——设"权威覆盖率门"。

**Cheeva Thai**：核实其米其林/黑珍珠状态（泰餐、起源一桌私房菜、提前半年预约），无论是否星级都补入，归**亚洲·泰国**。

## 八、实体名称交叉验证与复验（治"佰荣→白茸"，底层数据准确性）

### 1. 名称权威源优先级（正名以此为准）
官方招牌/公众号/小程序/官网 ＞ 工商注册名(企查查主体) ＞ 米其林/黑珍珠官方名单名 ＞ 地图POI官方认领(高德/腾讯) ＞ 大众点评官方商户名 ＞ UGC(小红书/抖音/携程笔记，常有同音错别字)。
**正名需 ≥2 个 a–e 类权威源用字一致；UGC 异写不得作正名。**

### 2. 采集契约（raw 字段）
`name`=权威正名；`name_verified`=true（≥2 权威源一致才置）；`name_source_urls`=支撑 URL；`aliases`[]=异写/简称/拼音/英文/UGC 同音字（用于搜索召回，不用于展示）；权威源之间用字冲突 → `name_conflict` 标人工裁定。

### 3. 实体对齐增强（stage2）
同地址/坐标/电话下跨源名称归一比对：同音不同字（白茸/佰荣/白荣/百荣）、近形字、繁简、拼音、子品牌后缀（白茸小鲜/小白茸）。
- **同店异写** → 合并、正名为准、异写入 aliases；
- **近名异店**（读音近但地址/品牌/菜系不同）→ 保留为独立实体，禁止误并。

### 4. 全库名称复验（新增 name audit 质量门，随保鲜周期跑）
逐家拉权威源名称比对库内 `name`，找出同音/近形错字，生成"错误名→正名→依据URL"修正任务；修正成对迁移标签后改正名。

### 5. 已核实案例
- **白茸 Bai Rong** = 中餐·鲁菜(山东)·米其林指南入选，BFC 北区2幢104a（中山东二路558号），名出牡丹别称、胶东海鲜；被误写"佰荣"，须改正；
- 南京东路温州苍蝇馆"白荣"（温州三拼/虾子肉、4桌）是**另一家**，核实正名、勿与白茸误并；
- **白茸小鲜**（瑞虹太阳宫）、**小白茸**（森兰，待开业）为子品牌，按在业状态独立收录。

## 附录 A · 日料面类三级细分（亚洲·日本）

面类不是一个"拉面"格子，而是「**拉面 / 荞麦面 / 乌冬面**」三个**同级二级**，各自再细分；综合面坊挂"面"食材 + 形式标签。

### A1 拉面（按汤底/流派拆叶子）
- 博多·九州豚骨（细面白汤）：本场博多、一风堂、博多一幸舍、豚王

- 二郎系（豪放、大量配菜）：青山制面

- 熊本黑蒜 / 味噌 / 麻辣味增：青山制面等

### A2 荞麦面 そば（独立品类，非拉面）

## 附录 B · 日料 Omakase 板前单列（亚洲·日本）

- **Omakase（おまかせ，厨师发办）**：板前落座、无固定菜单、按当日食材由主厨逐贯/逐道发办，是与"寿司（可单点 / 含桌位）"不同的业态，**单列为菜系叶子「Omakase 板前」（cid 325，与寿司 86 同级，parent=日料）**。
- 与"怀石 / 会席"区分：怀石(97)是多道式正餐、有席位顺序与程式；Omakase 以板前一贯出餐、即时互动为主。
- 挂法：寿司 omakase 专门店（如鮨照类）挂「Omakase 板前」+「寿司」；板前烧肉 / 天妇罗 / 铁板烧 omakase 同理多挂对应叶子。
- 以单点 / 固定套餐为主、非厨师发办的寿司店仅挂寿司，不挂 Omakase。

## 九、标签地毯扫描引擎（配置驱动，治"新标签无实施机制"）

1. **可定制词根注册表**：一个标签 = 一条配置（标签名 + 多语种/黑话词根 + headline 范围 + 证据要求）；**新增标签只加词根、不改代码**。
2. **地毯式扫描**：范围店 × 标签词根，多源（官方菜单/米其林黑珍珠页/媒体/小红书正文+评论区/点评/抖音/B站）检索，命中须有具体菜品 + URL。
3. **首批标签 Off Menu**（隐藏菜单/主厨私藏/即兴盲盒/主厨发办/裏メニュー），挂在米其林、黑珍珠 headline；命中店 → stage2 挂载，扫描中发现的未收录店（醉东、唐香）自动转补录。
4. **已核实**：LING LONG(冬瓜)、遇外滩、荣府宴/新荣记、米其林江西菜(莲花血鸭)、言盐/La Bourriche133、唐阁 均有 off menu；「醉冬」正名=**醉东 Oriental House**（黑珍珠台州海鲜餐酒，未收录）；「唐香」须与朗廷「唐阁」区分、核实后补录。
