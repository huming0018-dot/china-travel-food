## 关键发现

1. **翠蝶品牌分店差异大**：BFC店（636）纯营销轰炸建议下架，北外滩店（639）和One ITC店（640）有真实堂食评价和排队证据可留。
2. **板前/omakase川菜需警惕**：633板前川菜信息极度不透明；630花椒树虽有名但自称"不是川菜"且差评多。
3. **沉浸式餐秀≠川菜馆**：632蜀宴赋本质是文化体验消费，口味被表演稀释。
4. **SoftShanghai背书的老吴家（625）**是本批证据最硬的店，海外媒体+本地食客双验证。
5. **袍哥川小馆（621）**是典型的快采时从大众点评抄的团购店，几乎无独立堂食证据。
