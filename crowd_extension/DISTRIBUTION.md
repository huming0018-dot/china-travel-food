# 发一个链接，按设备安装

### 后台与唤醒续作（Mac 轻量包当前行为）

首次自愿同意并启动后，浏览器进程运行时在不激活的工作标签页后台采集；没有普通窗口时创建最小化、不主动获取焦点的工作窗口。Mac 睡眠时不执行，唤醒后周期闹钟补做调度；浏览器重启后从持久化的运行状态续做。只有仍在运行的身份会恢复，手动停止、退出、验证码、限流和登录失效均保持暂停，须本人处理后继续。

调度使用 Chrome 120+ 已支持的 30 秒周期闹钟，并在运行中的 worker 每次加载/执行时检查并补建。任务状态保留原冷却、配额和回传重试时间；浏览器重启或相邻调度间隔超过两分钟时重新打开未完成页面并重置停留。该间隔只是挂起检测启发式，不是操作系统唤醒通知，不能识别每一次短休眠。被浏览器回收或缺失的工作标签页自动重建，证据回执 UUID 不改写。浏览器退出期间插件不能执行，也不能自行启动浏览器；重新启动浏览器后会恢复未停止的任务。浏览器可能延后后台调度，不承诺固定秒数内恢复。闹钟行为依据 [Chrome 官方文档](https://developer.chrome.com/docs/extensions/reference/api/alarms)。

已经加载过内测插件时，覆盖原插件目录的内容，再点扩展管理页的刷新图标；不要先卸载，以保留单设备邀请对应的本机身份。云端状态机/Chrome API 模拟检查验证恢复、停止及证据保留；真实 Mac 休眠/唤醒和平台回传仍需实机验收。
