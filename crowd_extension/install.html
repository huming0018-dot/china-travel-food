已自动检测你的电脑系统，为你推荐最省事的安装方式。无需 Python，全程图形化点击即可。

正在检测系统与浏览器…

🖥 你的系统：macOS 推荐 · 双击即装

1
点击下方下载 安装.command（这是你电脑的安装器，不是插件本体）
2
在「访达」里找到下载的文件，双击它
3
若系统提示「无法打开」：右键 → 打开 → 仍要打开（仅首次）
4
脚本会自动：解压插件 → 打开 Chrome 扩展页 → 复制插件文件夹路径到剪贴板
5
在扩展页右上角开启「开发者模式」→ 点「加载已解压的扩展程序」→ 按 ⌘V 粘贴路径 → 回车
⬇️ 下载 macOS 安装器 直接下载插件 zip

安装器是纯脚本（约 20 秒），会自动探测 Chrome / Edge / Brave，谁在就用谁打开。无需任何开发环境。

🖥 你的系统：Windows 推荐 · 双击即装

1
点击下方下载 安装.bat（这是你电脑的安装器，不是插件本体）
2
在「下载」文件夹找到它，双击运行
3
若出现蓝色「更多信息」提示 → 点击「仍要运行」（仅首次，脚本仅解压+打开浏览器）
4
脚本会自动：解压插件 → 打开 Chrome 扩展页 → 复制插件文件夹路径到剪贴板
5
在扩展页右上角开启「开发者模式」→ 点「加载已解压的扩展程序」→ 按 Ctrl+V 粘贴路径 → 回车
⬇️ 下载 Windows 安装器 直接下载插件 zip

安装器是纯批处理脚本，自动探测 Chrome / Edge / Brave，谁在就用谁打开。无需任何开发环境。

🖥 你的系统：Linux / 其他 手动安装

1
下载插件 zip 并解压到任意文件夹（如 ~/food-crowd）
2
打开 Chrome 或 Edge，地址栏输入 chrome://extensions（Edge 为 edge://extensions）
3
右上角开启「开发者模式」
4
点「加载已解压的扩展程序」→ 选择刚才解压出的文件夹
⬇️ 下载插件 zip

📱 检测到 Android 设备 手机版可用

1
安装 Kiwi Browser（Google Play 免费，Chromium 内核，支持 Chrome 扩展）
2
下载插件 zip，用 Kiwi 打开或先解压
3
Kiwi 地址栏输入 chrome://extensions → 开「开发者模式」→ 「+ 从 .zip/.crx 加载」→ 选 zip
4
填写参与编号 → 打开小红书页面 → 自动采集
⬇️ 下载插件 zip 📄 手机版详细教程

iPhone 暂不支持（苹果系统限制第三方扩展加载）。手机与电脑同一任务池，可换设备续采。

📱 想在手机上采集？

1
Android 手机：安装 Kiwi Browser，加载同一插件 zip —— 与电脑完全同步
2
iPhone：暂不支持（苹果系统限制），建议用电脑或 Android 手机
📲 查看手机版安装教程

✅ 安装完成后（三步开始采集）

1
点浏览器右上角拼图图标 🧩 → 找到「众包美食家」→ 点「选项」
2
填写你的参与编号（报名时自动生成，形如 P-XXXXXX），阅读并同意《参与协议》
3
回到小红书页面（需已登录你的账号），点插件图标 → 「▶ 启动采集」
✅ 之后全部自动：自动领任务 → 自动搜索 → 自动回传 → 自动领下一个任务。无需任何手动操作。
⚠️ 尚未报名？先回 报名页 获取参与编号（立即可用，无需审核）。
