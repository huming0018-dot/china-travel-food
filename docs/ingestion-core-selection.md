## 保留核心但不能称无缺陷
- **stage1 数值门**：taste=NaN 可绕过范围比较并产出 accepted。应有行为是拒绝非有限数；目前未修复。
- **stage2 实体对齐**：同名、同区但明确不同地址被判 update，可能合并不同分店。该缺陷不代表所有正常对齐不可用；不能把当前策略称通用实体工具。
- **stage3 回读**：计划 price_avg=60，回读为999，仍可报告 ok。已有回读只确认有限字段/存在性，不能当完整写入一致性验收。

这些是实际正常路径之外的局部缺陷，单列后续修复，而非通过删模块“消灭问题”。来源分类/引文关键词只是启发式，不验证 URL 内容、作者独立性或事实真实性。
