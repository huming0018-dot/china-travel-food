# 不吃素

## 是什么

**唐香老板虎爷**带着 **唐香的张健师傅**、**田老师**合伙开出的川味 bistro，2026 年新年开业。

**定位**：与唐香（高端 Obscura）完全不同的形态——不奢华、温柔、日常。

**空间**：上海弄堂里，纸糊大吊灯、小竹椅、**手写当日菜单**。**灶台离餐桌仅十米**。

## 菜单（2026 年初）

| 菜 | 描述 |
|---|---|
| 凉拌鲨鱼皮 | "巨脆又一点辣度"，很少见 |
| 卤拼 | 猪耳、牛舌、牛腱子、菌菇、大肠，各有风味 |
| 拆蟹滑蛋 | 珍宝蟹拆肉，蛋液完全包裹，蛋香混海鲜甜 |
| 无水清汤牛肋 | **完全用萝卜榨汁做汤底**，极清甜 |
| 双味麻婆豆腐 | 第二味是**自制臭豆腐**（不是堆高级食材） |
| 回锅鲍鱼响螺片 | 响螺片硬脆、鲍鱼软嫩 |
| 笋子牛背筋 | 腌笋与牛肉分别调味，汤汁配葱油饼 |

**从菜单能读出虎爷的成本哲学**：没有昂贵食材堆砌，靠**工序与巧思**（萝卜汁汤底、自制臭豆腐）做记忆点。

## 为什么这张卡重要

**它是"虎爷系"的第二个样本**，且与唐香形成对照：

| | 唐香 Obscura | 不吃素 |
|---|---|---|
| 定位 | 高端 fine dining | 弄堂 bistro |
| 客单 | 高 | 低 |
| 主厨 | DeAille | 张健师傅（唐香出身） |
| 投资人 | 虎爷 | 虎爷 |
| 策略 | 性格鲜明、极致 | 极致成本控制 |

**同一个投资人，用两种完全相反的模型试水。** 这说明虎爷不是"押注单一风格"，而是"押注不同客群的极端值"。

## 与 WIP 的关联（待证）

用户观察到 WIP 团队与虎爷"很熟"。
