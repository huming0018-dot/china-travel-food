## 三条可复用的判断

### 1. 双主厨结构已成主流

**WIP（Shui_Boi + zhouren）、解香楼（任海鹏 + 吴萍瑶）都是双主厨。**

- 一人偏研发/对外，一人偏后厨管理，往往对外只露一个
- 只追一个人会漏掉一半信息
- 主厨离开时另一人常留任（任海鹏走，吴萍瑶可能仍在解香楼）

### 2. 知识转移比"师承"更实在

两条完整链条：

```
曾超敬（明阁）──USB 全部菜谱──→ 张一峰（潮上潮米三）──→ 潮1/2
俞斌（紫萱）──制度＋研发体系──→ 任海鹏 + 吴萍瑶 ──→ 当霁（上海）
```

**不是"一个师父带一个徒弟"，是把可复制的东西（菜谱库、研发制度）交给团队。**

### 3. 资本线与师承线平行

```
师承线决定技法从哪来：曾超敬→张一峰、俞斌→任海鹏
资本线决定谁能开、开成什么样：虎爷→DeAille 掌 Obscura、虎爷→张健做不吃素
```

**某些餐厅的菜系走向，取决于投资人审美，不是主厨师承。**
