# 明阁 / 朗廷系

## 体系结构

```
朗廷酒店集团（Langham）
   ├─ 唐阁（T'ang Court）—— 邝伟强，香港米其林三星；上海唐阁 2017 米三
   └─ 明阁（Ming Court）
         ├─ 曾超敬（2004–2014 行政总厨，缔造米二）
         │     └─→ 张一峰（共事一年，受赠全部菜谱）
         │            └─→ 北京潮上潮（米三）→ 潮1/2
         └─ 曾超烈（曾超敬之兄，2014 接棒）
```

## 明阁的两个阶段

| 时期 | 掌舵 | 成绩 |
|---|---|---|
| 2004–2014 | **曾超敬** | 2009 米一 → 2010 米二 → 连续多年蝉联 |
| 2014 后 | **曾超烈** | 延续米其林荣耀 |

**2004 年前的明阁只是一家寻常酒店餐厅**，是曾超敬用十年把它做成"名满香江的粤菜名府"。

## 张一峰从这里带走了什么

不是"学了几道菜"，是**整套菜谱库**：

- 曾超敬把**所有菜谱存在 USB** 里交给张一峰
- 涵盖：点心烧味、过年的金玉满堂、龙凤呈祥、**每个月份的菜式**
- 张一峰带这个"武林秘笈"北上，在**没有人脉**的情况下立足
- 最终北京潮上潮拿到**米其林三星**

> "这只『手指』帮了我很大的忙……这样我才可以在没有人脉的情况下，在内地立足。"

**这是一种罕见的传承方式**：不是口传心授，是**把可复制的知识资产直接给出去**。

## 师徒关系的三种表述

| 谁 | 怎么说 |
|---|---|
| 张一峰 | "是师父！" |
| 曾超敬 | "朋友啦，是无话不谈的朋友！" |

**实际形态**：皇御园共事约一年 + 终身受用的菜谱赠予。比"同事"深，比"入室弟子"浅，但功能性更强。

## 与上海吉品轩的关系

吉品轩（上海，米二，伯衡 55）被评价"**真正传承『明阁』精髓**的一家粤菜馆"——张一峰掌勺时期。

上海朗廷系本身也有两家粤菜馆（唐阁、明阁），但评价认为吉品轩比它们更接近明阁本味。
