# CIA（美国烹饪学院）校友网络

## 这条线是什么

**CIA = Culinary Institute of America**，美国顶级烹饪学校。上海一批高端餐厅主厨的共同起点。

与「师承」不同：**校友关系不意味着同一师父**，只说明共享的训练体系与味觉语言。

## 已知成员

| 人物 | 现/曾任职 | CIA 后路径 |
|---|---|---|
| **Zee Zheng（郑云泽）** | fabula（米一）、Alea | 求学期间在 Le Bernardin（米三）、Dovetail（米一）、The Modern → 回国任泰安门 Sous Chef → 2022 创办 fabula |
| **水主厨** | WIP 未樸 | CIA → 潮1/2 → 采风 → 2026 上海开 WIP |

## 观察到的共性路径

```
CIA 求学（含在纽约米其林实习/工作）
  → 回国进入顶级餐厅（泰安门 / 潮上潮等）
  → 独立开店，主打"把中餐风味用西餐逻辑重构"
```

WIP（岭南风味解构）与 fabula（粤菜＋宁波 heritage＋欧洲技法）在方法论上高度同源，这可能是"同门"说法的真实所指。
