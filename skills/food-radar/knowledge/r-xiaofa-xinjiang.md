# 小法和他的朋友们

## 主理人：法路克（小法）

- **新疆人**，在上海的新疆朋友圈里较有名
- **不是科班厨师出身**——从"私厨梦"起步（朋友记述"他的私厨梦终于实现了"）
- 运营方式偏社群：即刻 App 有同名账号，用私厨 + homebar + pop up 组合运营

## 形态：私厨，不是常规餐厅

- **满 6 人开席**，人不够时老板娘会帮忙凑
- 宠物友好
- 曾在外滩**沙美大楼 2 楼**做晚宴 pop up
- 有 homebar 空间，可两处同时开席；天晴可在外院草坪

## 菜品方向

"新疆菜的 fine dining"——用新疆食材与风味做底，缝合多种菜系：

| 元素 | 具体 |
|---|---|
| 新疆 | 冬季牧场长毛羔羊棒骨、新疆牛油、阿克苏南瓜、新疆酸奶、抓饭 |
| 法餐／意式 | 技法与摆盘逻辑 |
| 川渝 | 自制麻辣底（新疆牛油 + 重庆香料，调低辣度适配上海） |
| 云南／广西 | 羊肚菌、鹿角菜、山胡椒油 |
| 自酿 | 各类趣味红酒（"中国红酒"） |

**招牌形式**：串串（每天有，19:00 起）、鲜汤底火锅、抓饭

## 为什么值得记

这是上海"**非科班主厨 + 社群运营**"的典型样本：
- 不靠米其林履历，靠**人脉与口碑**传播
- 私厨模式天然稀缺（满 6 人开席 = 每场固定客数）
- 与 WIP（科班 + 解构）、自慢（店 + 私房菜）形成三种完全不同的"小规模高端餐饮"路径
