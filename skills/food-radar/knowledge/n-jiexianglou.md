# 解香楼系 / 紫萱集团

## 体系结构

```
俞斌（1993 楼外楼学徒 → 紫萱烹饪团队领衔）
   ├─ 解香楼（杭州西湖八盘岭路1号，紫萱度假村，2026 米二）
   │      └─ 双主厨：任海鹏 ＋ 吴萍瑶
   ├─ 潮玖（潮汕菜，俞斌创办，任海鹏主理）
   └─ 当霁（上海虹口，任海鹏带原班团队，2026-10）
```

## 俞斌（这条线的根）

- **1993 年**在**杭州楼外楼**学徒起，深耕杭帮菜与精致中餐
- 任职**紫萱度假村**期间建立**新菜研发体系**，带团队打造**多家米其林与黑珍珠餐厅**
- **2026 年**解香楼晋升**米其林二星**
- 同年获**沪苏浙米其林指南导师厨师奖**
- 头衔：中国浙菜研究会副会长、浙江省餐饮行业协会名厨委执行主任、世界中餐业联合会名厨委浙江省区域主席、法国埃科菲厨皇协会杭州区会长
- 现任**浦江名荟**行政总厨（"创意江南菜掌门人"）
- 自述理念："传承、厚味"

**关键判断**：俞斌不是"一位名厨"，而是一个**体系输出者**——紫萱集团下多个品牌、多家米其林/黑珍珠，都出自这套研发体系。凡标榜"江南菜/浙江菜"的新店，主厨背景大概率能追到这条线或其分支。

## 解香楼

- 地址：杭州西湖区**八盘岭路 1 号 紫萱度假村**内
- 人均约 ¥700，**需提前 3–4 天**
- 所属：**紫萱集团**
- 荣誉：2025 黑珍珠；**2026 米其林二星**
- 招牌：独头蒜烧江鳗、江南文火小牛肉
- 空间：浙江木构 + 日式庭院美学，青砖铜饰
- 市场认知："**住在四季，吃在紫萱**"

## 双主厨：任海鹏 + 吴萍瑶

腾讯新闻 2025-10 报道明确：

> "而如今由年轻的**双主厨**接任（**任海鹏师傅、吴萍瑶师傅**）"

- **任海鹏**：浙江台州人，2013 进解香楼学徒 → 2020 主厨 → 2025 黑珍珠年轻主厨奖 → 2026 上海当霁
- **吴萍瑶**：解香楼另一位主厨，**履历完全未查到**（这是本卡最大缺口）

**注意**：任海鹏离开去上海开当霁后，解香楼由谁掌勺，目前无公开信息。若仍是吴萍瑶独撑，那解香楼的"双主厨"结构已被拆散。

## 潮玖（同一体系下的潮汕菜）

- **俞斌创办**，**任海鹏主理**
- 定位：新派潮汕菜，理念"守本味、精工序、轻繁复、重本鲜"
- 以潮汕本港海鲜为核心，清蒸、卤水、浓汤
- 首发杭州，2026 年进上海开首店
- 2026-10-24 有"十二款珍藏"主题活动

**这条支线说明**：紫萱集团在做**跨菜系扩张**（杭帮 → 潮汕），由俞斌搭体系、任海鹏执行。
