# 餐饮模式公式（restaurant patterns）

把餐厅拆成**可识别的模式**，用于两件事：**按场景推荐**、**指导社媒爬虫的关键词与指标**。

这套公式来自 2026-10 对 9 家上海餐厅的实测归纳（WIP、ONCUE、fabula、自慢、小法、当霁、醉东、富臨联弹、沪依）。

## 四种模式

### 模式 A｜科班 + 解构

```
顶级履历（CIA／米其林三星研发／名店 Sous Chef）
  + 中餐风味内核（岭南、粤、宁波、本帮）
  → 用西餐逻辑重组中餐
  → 结果：菜单有"解构/重塑"痕迹，且常拒绝给菜系命名
```

**识别信号**
- 主厨履历含：Odette、泰安门、Le Bernardin、The Modern、潮上潮
- 文案出现：`解构` `重塑` `重新演绎` `拿掉框架`
- 店名西化或不直白：WIP、ONCUE、fabula
- 座位少（6–20）、开放式厨房、主厨在场

**代表**：WIP 未樸（岭南风味 × 液氮/低温慢煮）、fabula（粤菜 × 欧洲技法）、ONCUE（拒绝命名，Odette 研发主厨底子）

**本质**：**用技术密度换溢价**，卖的是"别人做不出的味道"。

### 模式 B｜店 + 私房菜（双层结构）

```
外层：低门槛引流（bistro／清酒／甜品／下午茶）
内层：高客单私房菜，熟客制、只加微信
→ 一个地址做两种生意，用外层筛客、内层赚钱
```

**识别信号**
- 同一地址出现**两个业态名**
- 私房菜"只接受加老板微信订位"，不走平台
- 主理人有强个人标签（如"老虎"）
- 藏酒/藏茶量惊人——本质是做圈层身份

**代表**：自慢（楼下自慢酒家 170+ 款清酒 bistro，楼上自慢私房菜一张桌）

**本质**：**用信息差和关系做壁垒**，卖的是"你进得去"。

### 模式 C｜社群 + 私厨

```
非科班主理人 + 强人脉/社群运营
→ 满 N 人开席、pop up、homebar
→ 靠口碑与个人账号传播，不靠媒体投放
```

**识别信号**
- 主理人有其他行业背景（服装、设计、媒体、艺术）
- 文案出现：`满X人开席` `帮凑人` `pop up` `homebar` `宠物友好`
- 主理人在小红书/即刻持续发内容，本人即 IP
- 地址不稳定（常有快闪）

**代表**：小法和他的朋友们（法路克，新疆人，满 6 人开席）

**本质**：**用社交资本替代资本投入**，卖的是"认识这个人"。

### 模式 D｜体系迁移

```
成熟团队整建制搬到新城市/新店
→ 出品稳定、磨合成本低
→ 风险：食材供应与客群口味的水土不服
```

**识别信号**
- 文案出现：`原班团队` `首次进入上海` `XX 餐厅主厨带队`
- 开店即有多篇通稿、团队规模大
- 与原城市名店的菜单高度相似

**代表**：当霁（杭州解香楼原班主厨团队 → 上海）

**本质**：**用已验证的体系换确定性**，卖的是"和那家店一样好"。

## 推荐映射

| 场景 | 首选模式 | 理由 |
|---|---|---|
| 一个人吃、想被照顾 | **B** | 主理人在场，能聊、能加菜 |
| 两人约会、要仪式感 | **A** | 菜品有设计感，环境精致 |
| 多人商务、要包房 | **D** 或连锁 | 出品稳定、有包房、能开票 |
| 带懂吃的朋友、要"别人订不到" | **B / C** | 稀缺感本身就是招待 |
| 想快速判断一家新店值不值得跑 | 看它属于哪一类，再对照该类的`失败模式` | 见下 |

## 各模式的失败模式（用于避雷）

| 模式 | 典型翻车点 |
|---|---|
| A 科班解构 | 技术炫技压过好吃，"每道都有想法但没有一道想吃第二口" |
| B 店+私房菜 | 外层引流太成功，内层订不到；或私房菜品质依赖主理人在不在 |
| C 社群私厨 | 主理人精力有限，扩张即崩；地址变动导致扑空 |
| D 体系迁移 | 换了城市食材跟不上，菜单"形似神不似" |

### 抓取优先级指标

| 指标 | 高价值阈值 | 说明 |
|---|---|---|
| 座位数 | ≤ 20 | 稀缺性核心指标 |
| 人均 | ≥ 800 | 高端分水岭（上海 2026） |
| 需提前 | ≥ 7 天 | 反映真实供需 |
| 是否有独立主厨署名 | 有 | 无署名多为资本项目 |
| 是否有师承可追 | 有 | 决定能否挂进关系网 |

## 递归追查规则（防止无限扩散）

**值得继续建卡的节点**
1. 米其林星级 / 黑珍珠钻级主厨
2. 有明确**拜师**关系的人（不是校友、不是同事）
3. 四手联弹的另一方（联弹是高频社交信号）
4. **同一地址的前身店**（常揭示主厨流动方向）

**不值得追**
- 连锁品牌的单店店长（不是主厨）
- 无具名主厨的餐厅
- 纯资本运作项目（无个人风格）

**深度上限**：从"用户实际预订的店"出发，**最多两跳**（店 → 主厨 → 其师承/前东家）。

**每跳必须回答**：这个关系对"下次订位或理解菜单"有什么用？答不上来就停，否则会滑向行业八卦。

## 证据分级（与 knowledge-cards.md 一致）

- `confirmed`：≥ 2 个独立来源一致
- `partial`：单一来源，或关键字段（地址/主厨）有一项未证
- `unverified`：仅 UGC 提及

**硬事实（人名、日期、师承）不接受单一小红书笔记作为定论。**
