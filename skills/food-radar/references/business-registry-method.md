# 工商信息推演法（business registry inference）

**核心命题**：工商登记是**唯一能证明"钱和人的关系"**的公开数据。菜单会换、主厨会走，但股权变更会留痕。

用于回答三类问题：
1. 这家店**真正**是谁的？（媒体说"主理人"≠ 股东）
2. 什么时候**换的人**？（比报道更精确）
3. 是不是要**关了**？（比"排队变短"可靠）

---

## 一、能查到什么，能推断什么

| 字段 | 可推断 |
|---|---|
| **股东名单** | 谁真正拥有（vs 谁是门面） |
| **法定代表人** | 谁承担法律责任（常与实际经营人不是同一人） |
| **历史变更** | 股权转让→换老板；法人变更→换操盘手；经营范围变更→转型 |
| **对外投资** | 控股结构、是否集团化 |
| **分支机构** | 真实扩张节奏、区域重心 |
| **成立 / 注销日期** | 开张关张的**精确时间** |
| **注册资本 / 实缴** | 真实投入规模（注册资本虚高很常见，看实缴） |
| **参保人数** | 实际员工规模（比"百人团队"的宣传可靠得多） |
| **经营异常名录** | 欠税、失联、未年报 → 关张前兆 |
| **司法案件** | 供应商追债、劳动纠纷 → 现金流紧张的信号 |

---

## 二、五种典型推演

### 1｜主厨是不是真老板

| 工商情况 | 结论 |
|---|---|
| 股东名单有主厨本人 | **真合伙**，"主理人"名副其实 |
| 股东名单无主厨 | **雇佣关系**，媒体称"主理人"要打折 |
| 主厨是法人但无股权 | 责任承担者，不是受益者 |

**例**：WIP 官方称"By Chef @Shui_Boi & @zhouren"，但股东是谁**未查到**。这时不能假设主厨=老板。

### 2｜换帅的精确时间

**法定代表人变更日 ≈ 实际控制权转移日。**

把它与公开报道的"接任"时间对照，能发现：
- 媒体报道滞后多久
- 是否存在"先换人后官宣"

**例**：吉品轩从张一峰到李伟的交接，公开报道只有模糊的"2022 年李伟加入 Hakkasan"，实际股权/法人变更日才是硬时间。

### 3｜关张的预警（三步）

```
经营异常名录    → 欠税 / 失联 / 未年报
司法案件激增    → 供应商追债、劳动仲裁
分支机构密集注销 → 战略收缩
```

**这三条比"最近排队变短了"可靠一个量级**——后者可能是季节、天气、热搜。

### 4｜资本关系：找出"系"

- 两家餐厅有**共同股东** → 同一资本方
- 同一投资人出现在多家店 → 可定义为"XX 系"
- 投资人自己的**创业史**决定他能投什么（见下）

### 5｜扩张节奏的真伪

**分支机构成立时间 = 真实开店节奏**。

对比宣传口径（"明年开 10 家"）与实际注册数量，能判断是激进还是保守。

## 三、拿不到工商数据时的次优路径

**本次实战教训**：企查查 Connector 未连接 + 公开搜索查不到 WIP 主体全称，工商这条路直接断掉。

**替代方法**：**查投资人的创业史**。

**为什么有效**：投资人的**钱从哪来**，决定了他能投什么、投多久、抗不抗得住亏损。

**虎爷案例的完整推演链**：

```
搜"虎爷 餐饮投资人"
  → 凤凰网专访「亚洲第一女厨的幕后老板：虎爷」
  → 提到多重身份（互联网人、民宿老板）
  → 换关键词搜"虎爷 发到家"
  → 青松基金「发到家创始人虎爷：温柔的硬派人生」
  → 真名林以宁
  → 查"发到家 融资"
  → 上海地奇网络科技，4 轮 5800 万，大润发战略投资，年 GMV 50 亿
  → 结论：这是有真实产业背景的连续创业者，不是玩票型投资人
```

**关键跳跃**：从"餐饮投资人"这个身份，反查到他的**本业**，才能真正理解他的投资逻辑。

## 四、操作流程

### 第 0 步｜确定主体全称

**简称查不到。** 四个地方能找到全称：

1. 纸质菜单/名片的版权页
2. 发票（开票方）
3. 小程序「关于我们」/「≡」菜单底部
4. 招聘信息（Boss 直聘、猎聘的公司主体）

### 第 1 步｜基础查询

```
注册信息 → 股东 → 实际控制人 → 主要人员 → 对外投资
```

### 第 2 步｜跨店比对

把该股东/法人名下的**所有**企业列出来，看是否在多家餐饮主体出现。

### 第 3 步｜时间线对齐

```
工商变更日  vs  公开报道日  vs  菜单改版日
```

三者不一致时，**以工商为准**。

### 第 4 步｜输出时分开标注

卡里必须把"股东"和"主厨"分成两栏，**不要混写**：

```yaml
shareholders: [人名/公司]     # 谁出钱
chefs: [人名]                 # 谁做菜
legal_rep: 人名               # 谁担责
```

---

## 四点五｜查投资人：必须看他「自己那家公司现在怎么样」

**只看历史成绩会误判。** 投资人当年做过什么，和他现在还有没有实力，是两件事。

### 虎爷（林以宁）实测案例

| 阶段 | 事实 |
|---|---|
| **2015–2017（高光）** | 发到家 4 轮融资 5800 万；大润发/飞牛网战略投资占股 40%；130+ 门店、年 GMV 超 50 亿；黄明端在其管理团队 |
| **2026（现状）** | 上海地奇网络科技：**失信被执行人 / 被执行人 / 限制高消费 / 经营异常**；**员工 1 人**（2024 年报）；法定代表人已换三次（谭嘉明→朱州芳→张耀文）；注册地址从静安**搬到金山枫泾**；**林以宁已不在股东与管理层** |

**判断**：他当年的成功**没有转化为持续的资本能力**。现在做餐饮投资，性质更接近"转型"而非"资本过剩"。

### 必查五项

| # | 指标 | 危险信号 |
|---|---|---|
| 1 | **登记状态** | 注销 / 吊销 / 迁出 |
| 2 | **风险标签** | 经营异常、失信被执行人、限制高消费、被执行人 |
| 3 | **员工人数**（年报） | 从几十/上百人掉到**个位数**——最硬的衰退信号，比任何新闻都准 |
| 4 | **法定代表人变更次数** | 频繁更换通常意味着责任转移或原实控人退出 |
| 5 | **注册地址** | 从核心商圈**搬到远郊/经济园区** = 收缩（金山、崇明这类） |

### 为什么这一条常被忽略

媒体写投资人时，永远引用他的**巅峰成绩**（"曾做到 50 亿 GMV"），不写他现在**还剩什么**。

而餐饮投资是需要**持续输血**的行为——一家 fine dining 从筹备到盈亏平衡通常要 12–24 个月。投得起和撑得住，是两种能力。

**所以看到"XX 投资人"时，第一反应应该是：他自己那家公司，现在什么状态？**

## 五、边界（必须声明）

1. **只能证明登记层面的关系**，不能证明实际经营关系
2. **代持常见**：实控人穿透可能断在自然人，断点处不代表真相
3. **个体户没有股东信息**：很多小店是"个体工商户"，查不到股权
4. **数据有滞后**：年报类信息按公示周期更新，可能滞后数月至一年
5. **不构成尽调结论**：这是食客视角的参考，不是投资建议

**三者交叉才能得出完整判断**：一个主厨的技法来源（师承）≠ 他的店归谁所有（股权）≠ 这家店属于哪种商业模式。

**最容易犯的错**：把"主厨很有名"当成"主厨是老板"。
